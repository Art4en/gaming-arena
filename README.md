# Gamer Arena

Site web : test de personnalité gamer, mini-jeux de réflexes (temps de réaction, aim trainer) et quiz de culture gaming (League of Legends, Valorant, Fortnite, Apex Legends) et quiz de jeux d'histoire (Cyberpunk 2077, The Witcher 3, Red Dead Redemption 2, The Last of Us, God of War).

## Démo en ligne

https://art4en.github.io/gaming-arena/

## Lancer en local

Aucune installation requise : ouvrir `index.html` dans un navigateur.

## Fonctionnalités

- Test de personnalité (20 questions)
- Mini-jeux de réflexes : temps de réaction, aim trainer
- Quiz de culture gaming
- Comptes et classements partagés via [Supabase](https://supabase.com) (voir `supabase-setup.sql` pour la structure de la base)

## Stack

HTML / CSS / JavaScript (vanilla), Supabase (base de données + authentification).
